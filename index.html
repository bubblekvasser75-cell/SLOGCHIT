``Теперь механика работает именно так, как вы описали: **Как это работает:** 1. **Диктор произносит слог** — при каждом шаге автоматически озвучивается нужный слог через Web Speech API (медленный темп, чуть повышенный тон для детской дружелюбности). Большая синяя кнопка динамика при этом пульсирует, показывая что идёт озвучка. 2. **Ребёнок выбирает из вариантов** — внизу появляются 3 карточки-слога (перемешанные). Нужно нажать на ту, которую только что сказал диктор. 3. **Пошаговое сборение** — для слов из нескольких слогов (МАМА, НОГА, СОБАКА) процесс повторяется: диктор говорит первый слог → выбор → диктор говорит второй слог → выбор → и т.д. Точки-индикаторы и слоты-карманы наглядно показывают прогресс. 4. **Кнопка «Послушать ещё раз»** — если ребёнок не расслышал, можно нажать на пульсирующий динамик и слог повторится. 5. **Подсказка** — подсвечивает правильную карточку жёлтой рамкой (но снижает количество звёзд). 6. По завершении — вспышка частиц, иллюстрация, экран результатов со звёздами.
